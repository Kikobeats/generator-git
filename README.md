[![NPM Status](https://img.shields.io/npm/dm/generator-git?style=flat-square)](https://www.npmjs.com/package/generator-git)

## Install

First, install Yeoman:

```bash
$ npm install -g yo
```

Later, install this generator:

```bash
$ npm install -g generator-git
```

## Usage

```bash
$ yo git
```
